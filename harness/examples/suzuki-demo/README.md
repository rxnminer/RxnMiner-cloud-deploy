# Suzuki coupling demo figure

`figure.png` is a deterministic, synthetic substrate-scope figure (one Suzuki coupling template
and a small grid of concrete examples) generated by the ChemRxn-Bench example generator. It is
not a published figure and carries no benchmark ground truth, so it is safe to use for smoke
tests and for trying edits to the Skill.

`expected_answer.json` is the oracle V2 extraction for the figure. A correct run reproduces every
reactant and product in it (compare canonical SMILES; array order does not matter).

```bash
bash docker/run.sh examples/suzuki-demo/figure.png out/suzuki-demo
python3 - <<'PY'
import json
from rdkit import Chem
def mols(v2):
    out = set()
    for e in v2.get("selected_examples", []):
        for step in e.get("steps") or [e]:
            for side in ("reactants", "products"):
                for m in step.get(side, []):
                    s = (m.get("E-SMILES") or m.get("smiles") or "").split("<sep>")[0]
                    mol = Chem.MolFromSmiles(s)
                    if mol is not None:
                        out.add(Chem.MolToSmiles(mol))
    return out
got = mols(json.load(open("out/suzuki-demo/answer.json")))
want = mols(json.load(open("examples/suzuki-demo/expected_answer.json")))
print("matched", len(got & want), "of", len(want), "expected molecules; extra", len(got - want))
PY
```
