# README media provenance

`product-workspace.png` is captured from the RxnMiner visual workbench with the bundled
`demo-figure` sealed replay. It uses the English blue/lavender interface and the same
source figure as the single website demo. It is a reconstruction, not a new extraction.

Figure authors: Suman Das, Stanna K. Dorn, and M. Kevin Brown.
DOI: https://doi.org/10.1002/anie.202523140
License: https://creativecommons.org/licenses/by/4.0/
The source figure is unchanged; interface, predictions, and bounding-box overlays are derived work.

`chemrxn-mark.svg` is the original project mark. Its filename remains stable for existing links.
